3-PRS 并联雕刻机器人

采用 3-PRS 三平移并联构型，完成运动学建模与反解推导，结合 OpenCV 视觉自动生成雕刻路径，STM32 三轴 PWM 同步控制

STM32运动学反解OpenCVPWM 同步SolidWorksMATLAB

项目背景与需求

本项目来自机器人创新实验室（2025.12-2026.01），目标是开发一款三自由度并联雕刻机器人。采用 3-PRS（Prismatic-Revolute-Spherical）三平移并联构型，相比传统串联机械臂具有刚度高、精度好、负载能力强等优势。系统整合了运动学建模、OpenCV 视觉路径规划和 STM32 多轴同步控制。

功能需求

  • 完成 3-PRS 并联机构运动学正解与反解数学模型推导
  • OpenCV 对雕刻图案进行预处理、轮廓提取、像素-世界坐标标定
  • 自动生成雕刻路径（G-code 风格坐标序列）
  • STM32 三轴 PWM 同步输出，结合脉冲计数闭环实现精确位置控制
  • MATLAB 仿真验证运动学模型正确性

核心实现思路与技术亮点

3-PRS 运动学建模与反解

3-PRS 并联机构由三条完全相同的 PRS 支链连接动平台与定平台，每条支链包含一个移动副(P)、一个转动副(R)、一个球铰(S)。反解即已知末端坐标 (x, y, z)，求解三条支链的驱动位移 (d₁, d₂, d₃)。

  • 建立定平台与动平台的坐标系变换关系
  • 利用约束方程（各支链的几何长度不变）推导反解公式
  • MATLAB 仿真验证：工作空间分析 + 反解精度验证
  • 末端坐标 → 三杆长度的映射在 STM32 中查表实现，避免浮点运算开销

OpenCV 视觉路径自动生成

图像预处理灰度化 → 高斯滤波 → 自适应阈值二值化 → 形态学开闭运算去噪。
轮廓提取findContours 提取雕刻路径轮廓，approxPolyDP 多边形逼近平滑路径。
坐标标定棋盘格标定法建立像素坐标系 → 世界坐标系的映射，输出毫米级坐标序列。

STM32 三轴同步运动控制

PWM 脉冲TIM1 三通道 PWM 分别驱动三轴步进电机，频率决定速度、脉冲数决定位移。
脉冲计数闭环TIM2 编码器模式计数各轴脉冲，与目标值比对实现位置闭环。
同步插补根据路径点间的距离比例分配各轴脉冲频率，实现三轴线性插补同步运动。

遇到的难点与解决方案

难点 1：3-PRS 反解公式推导复杂

现象：3-PRS 并联机构的约束方程涉及多变量耦合，手工推导易出错

解决：利用 MATLAB 符号计算工具箱进行解析推导，自动生成 C 代码嵌入 STM32。建立 Simulink 仿真模型验证反解精度，工作空间内误差 <0.1mm。

难点 2：三轴同步性差导致雕刻路径变形

现象：复杂曲线雕刻时路径与预期偏差明显，圆弧变形为多边形

分析：三轴各自独立发送脉冲，无插补同步机制。当路径方向变化时，各轴速度不匹配导致轨迹偏离。

解决：实现简单线性插补：路径分段后，根据三轴位移比例在定时器中同步更新 PWM 频率。将路径点间距从 1mm 加密到 0.1mm，配合更高脉冲分辨率，轨迹精度显著提升。

关键代码片段

📄 kinematics.c — 3-PRS 运动学反解
C /* 3-PRS 并联机构运动学反解：末端坐标 → 三杆长度 */ #define R_BASE 50.0f // 定平台半径 (mm) #define R_PLAT 30.0f // 动平台半径 (mm) #define L_ARM 120.0f // 连杆长度 (mm) typedef struct { float x, y, z; // 末端坐标 (mm) } EndEffector_t; typedef struct { float d[3]; // 三杆驱动位移 (mm) } JointSpace_t; void IK_Solve(EndEffector_t *ee, JointSpace_t *js) { // 3-PRS 反解：每条支链的几何约束 // |P_i + d_i * u_i - (ee + R * p_i)| = L_ARM for (int i = 0; i < 3; i++) { // 支链 i 在定平台上的安装角 float theta = i * 2.0f * PI / 3.0f; // 定平台连接点坐标 float Bx = R_BASE * cos(theta); float By = R_BASE * sin(theta); // 动平台连接点（考虑末端偏移） float Px = ee->x + R_PLAT * cos(theta); float Py = ee->y + R_PLAT * sin(theta); // 几何约束方程 → 求解 d_i float dx = Px - Bx; float dy = Py - By; float dz = ee->z; // d_i = z ± sqrt(L² - dx² - dy²) float disc = L_ARM*L_ARM - dx*dx - dy*dy; if (disc < 0) disc = 0; // 奇异点保护 js->d[i] = dz - sqrt(disc); } }
📄 path_planner.py — OpenCV 路径生成 (Python)
Python # OpenCV 雕刻路径自动生成 import cv2 import numpy as np def generate_path(image_path, scale_mm_per_px): # 读取图像 → 预处理 img = cv2.imread(image_path) gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY) blur = cv2.GaussianBlur(gray, (5, 5), 0) _, thresh = cv2.threshold(blur, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU) # 轮廓提取 contours, _ = cv2.findContours( thresh, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE) # 多边形逼近 → 平滑路径点 path_points = [] for cnt in contours: epsilon = 0.001 * cv2.arcLength(cnt, True) approx = cv2.approxPolyDP(cnt, epsilon, True) for pt in approx: x_mm = pt[0][0] * scale_mm_per_px y_mm = pt[0][1] * scale_mm_per_px path_points.append((x_mm, y_mm, 1.0)) # z=1mm 雕刻深度 # 输出 G-code 风格坐标序列 return path_points
