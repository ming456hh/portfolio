四轴无人机飞控系统

基于 STM32F103 + FreeRTOS 的双板四轴无人机系统：飞控板运行 4 任务实时调度，集成 MPU6050 姿态解算、串级 PID 控制、2.4G 无线通信与 VL53L1X 激光定高；遥控板通过摇杆 ADC + OLED 屏幕实现人机交互

STM32F103C8T6 FreeRTOS MPU6050 串级 PID 四元数姿态解算 卡尔曼滤波 Si24R1 2.4G VL53L1X 激光测距 PWM 电机驱动
1

项目背景与需求

本项目来源于尚硅谷嵌入式精品课程——四轴无人机，是一个从零搭建的完整飞控系统工程。 采用双 STM32F103C8T6 板卡架构（飞控板 + 遥控器板），运行 FreeRTOS 实时操作系统， 实现了从传感器数据采集 → 姿态解算 → 串级 PID 控制 → 电机输出 → 2.4G 无线遥控的完整飞控闭环。

项目按 11 个章节逐步迭代：从 FreeRTOS 移植、电源管理、LED 灯控、通信驱动、遥控数据协议、 飞行状态机、MPU6050 数据采集、姿态角控制、平稳飞行，到最终实现激光定高和 OLED 屏幕显示， 完整覆盖了嵌入式无人机开发的全部核心环节。

功能需求清单

  • MPU6050 六轴数据采集（陀螺仪 + 加速度计），采样率 ≥ 166Hz（6ms 周期）
  • 四元数互补滤波姿态解算，实时输出俯仰角 / 横滚角 / 偏航角欧拉角
  • 串级 PID 控制器：外环角度环（P） + 内环角速度环（PD），三轴独立调节
  • VL53L1X 激光 ToF 测距实现定高飞行，高度 PID 独立闭环
  • Si24R1 2.4GHz 双向无线通信，飞控与遥控器实时数据交互
  • 遥控器双摇杆 ADC 采样 + OLED 屏幕状态显示 + 按键交互
  • 飞行状态机：IDLE → NORMAL ↔ FIX_HEIGHT，含 FAIL 故障保护
  • 电池电量监测（IP5305T）+ 低电量自动关机 + ADC 电压回传
  • 系统连续稳定飞行，安全保护：油门 < 50 强制停转

核心实现思路与技术亮点

3.1 软件架构设计

飞控软件基于 FreeRTOS 多任务架构，划分 4 个核心任务。采用抢占式调度 + 时间触发混合模式， 飞行控制任务以 6ms (166Hz) 固定周期运行，通过 vTaskDelayUntil 实现精确时序控制。

  • flight_task（prio=3, 6ms）：核心飞控任务 — 读取 MPU6050 → 低通/卡尔曼滤波 → 四元数姿态解算 → 串级 PID → 电机混合输出 → 定高 PID（每 4 次即 24ms 执行一次）
  • com_task（prio=4, 10ms）：通信任务 — Si24R1 数据接收/发送、遥控连接状态维护、飞行状态机切换、电池电压 ADC 采集回传
  • power_task（prio=4, 10s）：电源管理 — IP5305T 电池电量读取，通过 FreeRTOS 直接任务通知接收关机指令
  • led_task（prio=1, 100ms）：状态指示 — 前灯指示遥控连接状态，后灯按飞行状态以不同频率闪烁（IDLE: 500ms / NORMAL: 200ms / FIX_HEIGHT: 常亮 / FAIL: 全灭）

3.2 姿态解算与传感器融合

低通滤波 对陀螺仪原始角速度数据进行一阶低通滤波（output = α·last + (1-α)·current），抑制高频噪声。
卡尔曼滤波 对加速度计数据使用卡尔曼滤波器（3 个独立 Kalman Filter 实例分别处理 X/Y/Z 轴），平滑因振动引起的剧烈波动。
四元数互补滤波 采用 Mahony 算法思路：利用加速度计修正陀螺仪积分漂移（Kp=0.8, Ki=0.0003），通过四元数微分方程更新姿态， 最终从旋转矩阵提取欧拉角（pitch 用 asin、roll 用 atan2、yaw 用陀螺仪 Z 轴积分）。使用快速平方根倒数算法 (Fast Inverse Square Root) 优化归一化性能。
偏航角处理 偏航角仅使用陀螺仪 Z 轴积分（无磁力计修正），设置 ±0.5°/s 死区过滤漂移噪声。

3.3 串级 PID 控制器设计

串级架构 采用外环角度环 + 内环角速度环的串级 PID 结构。外环以目标角度为输入、当前欧拉角为反馈，输出作为内环的目标角速度； 内环以目标角速度为输入、当前陀螺仪角速度为反馈，输出最终 PWM 修正量。三轴（俯仰/横滚/偏航）各有一套独立的串级 PID。
PID 参数整定 俯仰/横滚外环 Kp=-7.0，内环 Kp=3.0 / Kd=0.5；偏航外环 Kp=-3.0，内环 Kp=-5.0。内环引入微分项抑制角速度超调，外环仅使用比例项保证角度跟踪快速性。 调试过程中先整定内环（锁定角速度），再整定外环（锁定角度）。
电机混合 4 个电机的 PWM 输出 = 基础油门 + 俯仰修正 ± 横滚修正 ± 偏航限幅修正。偏航修正使用 Com_limit() 限幅在 ±100 内， 防止偏航修正过大影响升力。油门 < 50 时所有电机强制停转作为安全保护。
定高 PID 独立的高度 PID 控制器（Kp=-0.6, Kd=-0.2），以定高触发时的高度为期望值，VL53L1X 实时测量值为反馈，输出叠加到 4 个电机的油门基础值上。 由于激光测距数据更新较慢，定高 PID 以 24ms 周期（6ms × 4）独立计算。

3.4 2.4GHz 无线通信与状态机

通信协议 遥控器每 10ms 发送一帧数据（油门/偏航/俯仰/横滚各 0-1000、定高标志位、关机标志位），飞控板接收后回传电池电压。 若连续多次未收到数据则判定为 REMOTE_DISCONNECTED 状态，断开连接后自动切换到 IDLE 状态确保安全。
飞行状态机 设计 4 种飞行状态：IDLE（电机停转）→ NORMAL（PID 稳定飞行）↔ FIX_HEIGHT（定高模式）以及 FAIL（故障保护，逐步降低转速至 0）。 遥控器按键触发定高开关，FAIL 状态解除后通过 FreeRTOS 直接任务通知恢复通信任务。

遇到的难点与解决方案

难点 1：串级 PID 参数整定 —— 飞机剧烈振荡无法稳定

现象：起飞后飞机在俯仰/横滚方向持续振荡，振幅逐渐增大直至失控翻覆

分析过程：通过 Vofa+ 串口数据可视化工具实时绘制陀螺仪角速度曲线，发现内环角速度存在明显超调——微分项系数 Kd 过小，无法有效抑制角速度的快速变化。同时外环角度环 Kp 绝对值过大，微小的角度偏差被放大为过大的角速度指令。

解决方案：

  • 采用"先内环后外环"的分步整定策略：先固定飞机于单轴，只调内环角速度 PD 参数，确认角速度能快速收敛至 0
  • 内环稳定后再接入外环角度 P，从较小 Kp 开始逐步增大至角度响应迅速且无超调
  • 最终参数：外环 Kp=-7.0(P-only)，内环 Kp=3.0 / Kd=0.5(PD)，三轴独立调试完成后联调
  • 整定后飞机实现稳定悬停，姿态偏差在 ±2° 以内

难点 2：MPU6050 数据噪声导致姿态角漂移

现象：飞机静止时欧拉角缓慢漂移，尤其是偏航角在 30 秒内漂移超过 10°

分析过程：陀螺仪原始数据存在零偏和随机噪声，直接积分必然导致角度漂移。加速度计虽可提供绝对角度参考，但易受机体振动干扰。单一传感器无法满足精度要求。

解决方案：

  • 陀螺仪数据先经过一阶低通滤波器消除高频毛刺
  • 加速度计数据通过卡尔曼滤波器平滑振动尖峰（3 个独立 Kalman 实例）
  • 四元数互补滤波融合两者：加速度计修正陀螺仪积分的长期漂移（Kp=0.8），陀螺仪保证短期动态响应
  • 偏航角增加 ±0.5°/s 死区阈值，低于阈值的微小角速度视为噪声忽略
  • 最终静止时角度漂移 < 1°/min，动态跟踪延迟 < 10ms

难点 3：定高飞行时高度 PID 与姿态 PID 相互干扰

现象：开启定高模式后飞机在垂直方向上下波动，同时姿态稳定性变差

分析过程：高度 PID 输出直接叠加到 4 个电机的油门基础值上，但 VL53L1X 激光测距在飞机倾斜时测量的是斜距而非垂直高度。飞机姿态变化 → 激光测量值波动 → 高度 PID 误修正 → 电机转速变化 → 姿态进一步变化，形成正反馈环路。

解决方案：

  • 降低高度 PID 的执行频率至 24ms（飞行控制 6ms 的 1/4），减少高度修正对姿态环的快速扰动
  • 高度 PID 输出不参与姿态混合，直接均等叠加到 4 个电机上，避免引入不对称力矩
  • 高度 PID 使用较小的 Kp=-0.6，配合 Kd=-0.2 微分项抑制超调
  • 优化后飞机在定高模式下高度波动控制在 ±3cm 以内

PI 修正：积分项累积 + 比例项即时修正 GyroIntegError.x += AccGravity.x * KiDef; GyroIntegError.y += AccGravity.y * KiDef; GyroIntegError.z += AccGravity.z * KiDef; Gyro.x = gyroAccel->gyro.gyro_x*Gyro_Gr + KpDef*AccGravity.x + GyroIntegError.x; Gyro.y = gyroAccel->gyro.gyro_y*Gyro_Gr + KpDef*AccGravity.y + GyroIntegError.y; Gyro.z = gyroAccel->gyro.gyro_z*Gyro_Gr + KpDef*AccGravity.z + GyroIntegError.z; // 4. 四元数微分方程更新 (一阶龙格库塔) float HalfTime = dt * 0.5f; NumQ.q0 += (-NumQ.q1*Gyro.x - NumQ.q2*Gyro.y - NumQ.q3*Gyro.z) * HalfTime; NumQ.q1 += ( NumQ.q0*Gyro.x - NumQ.q3*Gyro.y + NumQ.q2*Gyro.z) * HalfTime; NumQ.q2 += ( NumQ.q3*Gyro.x + NumQ.q0*Gyro.y - NumQ.q1*Gyro.z) * HalfTime; NumQ.q3 += (-NumQ.q2*Gyro.x + NumQ.q1*Gyro.y + NumQ.q0*Gyro.z) * HalfTime; // 5. 四元数归一化 NormQuat = Q_rsqrt(squa(NumQ.q0)+squa(NumQ.q1)+squa(NumQ.q2)+squa(NumQ.q3)); NumQ.q0 *= NormQuat; NumQ.q1 *= NormQuat; NumQ.q2 *= NormQuat; NumQ.q3 *= NormQuat; // 6. 从旋转矩阵提取欧拉角 eulerAngle->pitch = asin(2*NumQ.q0*NumQ.q2 - 2*NumQ.q1*NumQ.q3) * 57.29578f; eulerAngle->roll = atan2f(2*NumQ.q2*NumQ.q3 + 2*NumQ.q0*NumQ.q1, 1 - 2*NumQ.q1*NumQ.q1 - 2*NumQ.q2*NumQ.q2) * 57.29578f; // 偏航角：仅用陀螺仪Z轴积分（无磁力计），±0.5°/s死区过滤噪声 float yaw_G = gyroAccel->gyro.gyro_z * Gyro_G; if (yaw_G > 0.5f || yaw_G < -0.5f) { eulerAngle->yaw += yaw_G * dt; } }
