STM32 桌面终端

STM32F103ZET6 + LVGL 图形界面 + ESP32 网络同步，128×128 TFT 屏实现「桌面时钟 + 环境监测 + 智能控制」一体化终端

STM32F103ZET6LVGL v8ESP32TFT LCD模拟 SPIDMA环形缓冲区PWM 调速软件 RTC
1

项目概述

基于 STM32F103ZET6 微控制器与 LVGL v8.x 图形库的多功能桌面终端系统。通过 128×128 TFT 液晶屏提供可视化人机交互界面，集成温湿度检测、光线感应、LED 控制、风扇 PWM 调速、蜂鸣器告警、时间天气同步等功能。系统经 USART2 与 ESP32 模块通信，定时获取网络时间与天气信息，实现「桌面时钟 + 环境监测 + 智能控制」一体化终端。

核心功能

  • LVGL 图形界面：开机动画（打字效果 + B 站 logo 弹跳 + 照片淡入）→ 登录界面（用户/密码 + 错误弹窗）→ TabView 四页主界面（Home / Led / Fan / Set）
  • ESP32 网络同步：27 字节帧协议解析网络时间与天气（11 种天气代码），异或校验失败自动丢弃，DMA 内存搬运 22 字节数据
  • 软件 RTC 时钟：年月日时分秒走时 + 大小月/闰年自动处理，ESP32 自动校时 + Set 页手动调时
  • 模拟 SPI 高速刷屏：GPIO 位带操作直接置位/复位，刷屏 28 FPS（标准库方式仅 14 FPS）
  • DHT22 温湿度：单总线 40 位数据解析 + 校验，2s 周期采集，失败保留上次值
  • 风扇 PWM 调速：H 桥方向控制（PE8/PE9）+ TIM PWM 占空比，0~100% 步进 10%，支持正反转
  • 自动灯光：光敏传感器 100ms 检测，AUTO（暗自动开）/ MANU（手动开关）双模式
  • 屏保防烧屏：30s 无操作进入屏保，时间标签左右往复平移动画，任意按键唤醒

核心技术实现

3.1 LVGL 图形界面设计

基于 LVGL v8.x 构建完整 UI 流程，128×128 分辨率、单缓冲（10 行像素）、TIM1 1ms 提供时基，中文字体与图标资源以 C 数组形式编译进 Flash：

3.2 ESP32 串口通信协议（时间 + 天气同步）

USART2 115200 8N1，ESP32 每 10 分钟发送一帧 27 字节数据，STM32 端用状态机 + 环形缓冲区 + DMA 完成可靠接收：

偏移长度内容说明
[0]10xAA帧头
[1]10x16 (22)数据区长度
[2..11]10日期 ASCIIYYYY-MM-DD
[12..19]8时间 ASCIIHH:MM:SS
[20]1天气代码0=晴…11=霾
[21..23]3温度 ASCII如 +25 / -03
[24]1校验和byte[1]~[23] 异或
[25..26]2CRLF帧尾
可靠性128 字节环形缓冲区避免高波特率丢字节；校验失败自动丢弃回到等待帧头；校验通过 DMA 内存搬运 22 字节

3.3 模拟 SPI 高速刷屏

LCD 驱动采用 GPIO 位带操作模拟 SPI 时序，直接操作 BSRR/BRR 寄存器置位/复位，避免标准库函数调用开销。

刷屏速率：官方库 14 FPS → 位带操作 28 FPS（提升 2 倍）

3.4 软件 RTC + 屏保防烧屏

软件 RTC：rtc_time_t 结构体每秒递增，time_add_one_second() 自动处理大小月与闰年（能被 4 整除且不能被 100 整除，或能被 400 整除）。

屏保：30s 无按键进入屏保，纯黑背景 + 大号时间，标签 X 轴 -20~+20 像素往复平移（1.5s 周期），防止 TFT 烧屏。

4

开发难点 & 解决方案

难点 1：LVGL 刷屏卡顿，界面不流畅

现象：128×128 TFT 用标准库 GPIO 操作刷新，实测仅 14 FPS，开机动画明显卡顿

根因分析：标准库 GPIO_SetBits/ResetBits 每次调用都要经过函数调用与参数解析，而 SPI 时序每一位都需要一次 GPIO 翻转，函数开销被放大数百倍。

解决方案：改用 位带操作（BITBAND），直接映射 BSRR/BRR 寄存器地址，一条指令完成置位/复位，跳过函数调用。配合 disp_flush 单缓冲 + 10 行分块刷新。

效果：刷屏速率从 14 FPS 提升至 28 FPS，动画流畅无卡顿。

难点 2：高波特率串口接收丢字节

现象：ESP32 以 115200 波特率发送 27 字节帧，STM32 主循环轮询接收偶发丢字节，导致校验失败、时间天气无法同步

解决方案：

  • 128 字节环形缓冲区：USART2 中断里只写入（RXNE 时取一字节入队），主循环非阻塞取出，中断与主循环分离，无需关中断
  • 帧解析状态机：RX_HEADER → RX_LEN → RX_DATA 三态，逐字节解析，校验失败自动回到等待帧头，不粘帧不误判
  • DMA 内存搬运：校验通过后由 DMA 将 22 字节从 rx_buf 拷到 frame，不占用 CPU 周期

难点 3：LVGL 时基被串口中断打断，计时不准

现象：串口频繁接收时，LVGL 时基抖动，时钟走时与动画出现卡顿/跳秒

解决方案：NVIC 分组设为 Group 2（2 位抢占 + 2 位子优先级），TIM1 时基中断设最高抢占优先级(0,0)，USART2 设(1,1)。确保 1ms 时基中断永不被串口打断，保证 LVGL 计时准确。

难点 4：TFT 长时间显示固定内容易烧屏

现象：桌面终端常年显示时钟，固定像素长时间点亮会造成 TFT 液晶烧屏（残影）

解决方案：30 秒无按键操作自动进入屏保，时间标签以 1.5s 周期做 X 轴往复平移动画（LVGL 动画框架），使像素不固定在同一位置，有效避免烧屏。

C /* USART2 环形缓冲区：中断只写，主循环只读 */ #define SERIAL_RX_SIZE 128 static uint8_t Serial_RxBuf[SERIAL_RX_SIZE]; static volatile uint16_t Serial_RxWrite = 0; static volatile uint16_t Serial_RxRead = 0; void USART2_IRQHandler(void) { if (USART_GetITStatus(USART2, USART_IT_RXNE)) { uint8_t ch = USART_ReceiveData(USART2); uint16_t next = (Serial_RxWrite + 1) % SERIAL_RX_SIZE; if (next != Serial_RxRead) { /* 未满才写入 */ Serial_RxBuf[Serial_RxWrite] = ch; Serial_RxWrite = next; } } } uint8_t Serial_GetRxFlag(void) { return Serial_RxWrite != Serial_RxRead; } uint8_t Serial_GetRxData(void) { uint8_t ch = Serial_RxBuf[Serial_RxRead]; Serial_RxRead = (Serial_RxRead + 1) % SERIAL_RX_SIZE; return ch; }
📄 uart_service.c — 帧解析状态机
C /* ESP32 -> STM32 帧: 0xAA | 0x16(长度) | 22字节 | 校验 | CRLF */ void uart_service(void) { static uint8_t state = RX_HEADER; static uint8_t idx = 0, len = 0; static uint8_t frame[22]; while (Serial_GetRxFlag()) { uint8_t ch = Serial_GetRxData(); switch (state) { case RX_HEADER: if (ch == 0xAA) state = RX_LEN; /* 帧头匹配 */ break; case RX_LEN: len = ch; idx = 0; state = RX_DATA; /* 记录长度 */ break; case RX_DATA: if (idx < len) { frame[idx++] = ch; } else { if (ch == CalcChecksum(frame, len)) { MyDMA_Transfer(); /* DMA 搬运 */ parse_packet(); /* 更新时钟/天气 */ } state = RX_HEADER; /* 回到等待帧头 */ } break; } } }

项目总结 & 个人收获

项目成果

  • 基于 LVGL 构建完整 GUI（开机动画 + 登录 + 四页主界面），128×128 TFT 刷屏 28 FPS，动画流畅
  • ESP32 串口帧协议可靠同步网络时间与天气，校验失败自动丢弃，10 分钟周期自动校时
  • 软件 RTC 时钟支持大小月/闰年，时间精确走时不掉秒
  • DHT22 温湿度、光敏自动灯光、风扇 PWM 调速、蜂鸣器告警多外设协同稳定运行
  • 屏保往复动画有效避免 TFT 烧屏，支持长期无人值守

个人收获

  • LVGL 图形界面开发：掌握了 LVGL 对象模型、动画框架、字体/图片资源集成、刷新回调与单缓冲机制
  • 通信协议设计：从帧结构定义、异或校验、状态机解析到环形缓冲区 + DMA，完整走通了可靠串口通信链路
  • 性能优化思维：通过位带操作将刷屏速率翻倍，理解了寄存器级优化对嵌入式性能的关键作用
  • 中断优先级设计：学会用抢占优先级保证时基中断不被打断，避免实时性抖动
  • 系统整合能力：将时钟、天气、温湿度、灯光、风扇、屏保等多功能整合为一体化终端

后续改进方向

  • 改用 STM32 内部 RTC 或 DS3231 模块，实现掉电时间保持
  • 扩展触摸面板（GT911/FT6236），替代物理按键实现触屏操作
  • 增加 SD 卡 + FATFS，实现历史环境数据日志记录
  • 利用工程内已有的 PID 模块，结合风扇与温度传感器实现闭环温控
